# 在 Mac 上安装

[English](en/INSTALL_MAC.md) | **简体中文** · [首页](../README.zh-CN.md)

Mac 安装包支持 Apple Silicon（M 系列）、macOS 14 或更新版本。需要已安装 Codex / ChatGPT 桌面客户端；920K 已通过 Codex 0.163.0-alpha.10.2 运行时的本地集成测试。Intel Mac 暂不支持；Windows 提供同版本的独立安装包。

## 普通使用者

1. [下载 Apple Silicon DMG](https://github.com/Fandy-ust/codex-context-control/releases/latest)，然后打开。
2. 打开 `Install Context Manager.app`，点击「安装 / 更新」。
3. 完整退出并重开 Codex。菜单栏自动出现 Context Manager 的闪电额度图标。
4. 若需要 Hook stats，在 Codex 的 `/hooks` 审核新增 hook。主面板和预算控制不依赖 hook 信任。

无需安装开发工具，无需申请 Developer ID。安装器把运行环境复制到稳定的本地支持目录；删掉安装器不会影响使用。不会把签名的 Codex 应用改成修改版。

当前公开预览包使用本地签名，**尚未 Developer ID 签名、公证**。如果 macOS 阻止打开，确认包来自项目所有者、校验文件匹配后，先尝试打开，再去「系统设置 → 隐私与安全 → 仍要打开」。受管理的 Mac 可能限制这种例外；遵守该设备的管理策略。[Apple 官方说明](https://support.apple.com/en-us/102445)

不要运行关闭 Gatekeeper 的全局命令。校验和只能发现传输损坏或与发布文件不一致，不能代替发布者身份验证。

## 安装位置

- 应用：`~/Applications/Codex Context Control.app`
- 控制代码与状态：`~/Library/Application Support/CodexContextControl`
- 内置运行环境：上述目录的 `runtime/`，使用不可变版本文件名
- 新增 Stop hook：`~/.codex/hooks.json`，保留其他 hooks 并备份

代码和应用先复制到临时目录，完成后再替换现有目录；复制失败保留旧安装。预算、备份和现有开关设置保留。

## 获取、更新与移除

仓库及 0.20.2 中英版预览安装包均已公开，可直接下载。Mac 与 Windows 使用统一版本，同时发布各自的单文件安装包。

更新：打开新版安装器，选择「安装 / 更新」。连接桥接升级后需重开 Codex；界面会保留实际状态与等待生效的区别。

移除：安装器内选择「移除安装」。应用、自动接入及本项目 hook 被移除，预算和备份保留。也可使用源码中的卸载命令。

首次安装包不包含约 478 MB 的可选修复运行时；普通预算、统计、拓展功能不需要它。

## 图标更新

应用与安装器使用同一份彩色图标；菜单栏使用圆环与三条横线的单色版本，自动适应系统外观，并保留实时用量圆环。菜单栏不是缩小后的彩色 App 图标。

新版安装器会结束旧菜单栏进程后再替换应用、启动新版。只在 Finder 中更换 App 图标，不会改变代码绘制的菜单栏图形。无需重置整个系统图标缓存。

## 语言

安装器与 App 均可选择「自动（按时区）／中文／English」，立即生效并保存在本机，更新时保留。自动模式对中国大陆、香港、澳门、台湾时区使用中文，其余使用英文；手动选择优先。[语言说明](LOCALIZATION.md)

## 920K / Computer Use

在设置中开启上下文拓展，可设置最高 920K；切换后重开 Codex。提前压缩修复需要替换核心，修改版缺少 Codex 官方签名身份，会导致 Computer Use 无法使用，因此已停用。920K 仅调整配置，保留官方运行时。更新会保留预算和语言，但关闭旧的提前压缩修复。

## 在线更新与本地缓存

首次安装后，可在应用里更新。启动时检查 GitHub（六小时内复用检查结果），之后每六小时自动检查；点击「安装更新」才会下载、校验和安装，完成后重开 Codex。预算、语言和缓存保留。启动自动加载本地聊天，后台增量同步，也可点击「同步本地聊天」。缓存用量是历史记录，不代表实时连接；仅在远端且尚未同步到本地的记录仍需 Codex 先同步。

更新成功后替换旧 App 和程序代码，删除不再使用的内置运行环境与已停用的修复核心，OTA 下载文件也会清理。仍被进程使用的旧环境暂时保留，应用启动后每五分钟再次检查。预算、语言、对话缓存和用户备份保留；手动下载的 DMG 不会自动删除。

升级继承会保留已有设置中的未知字段和原有用户数据。版本变化前，仅在支持目录的 `upgrade-backup/` 保存一份轻量配置快照，不复制 App、运行环境或聊天缓存；同版本重装不重复生成快照。

更新检查优先读取 Release 的公开 `update.json` 文件，失败时才使用 GitHub API；限流会遵守重试时间，连续手动点击也有冷却。检查失败时提供发布页入口。旧版更新器遇到 HTTP 403 的用户需手动覆盖安装本版一次，无需 GitHub Token。如果网络本身限制 GitHub 下载，仍需更换可访问的网络或手动下载。
