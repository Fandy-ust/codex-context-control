# 控制面板样式

原生 SwiftUI 界面参考 Codex 深色面板：接近黑色的背景、深灰圆角容器、细边框、蓝色容量值、胶囊轨道和白色圆形滑块。聊天列表使用低对比度选中背景。

![双滑条控件预览](assets/context-controls.png)

图片由真实原生控件使用合成预算渲染，仅用于展示样式，不代表当前聊天的运行时状态。

## 交互

- 上方控制实际可用窗口；下方控制自动压缩阈值。
- 压缩控件最大宽度为 480 点，轨道高度为 20 点；窗口轨道高度为 28 点。下方控件比上方更短、更细。
- 拖动或点击轨道按 1K 调整；两侧按钮和聚焦后的左右方向键可逐 K 微调。
- 保留原有快捷预设、比例联动、预检、提交和压缩确认。
- 右上角回转箭头重新载入已保存预算。
- 滑条保留原生辅助功能表示和数值，供读屏与辅助调节使用。

## 动效

蓝色区域中的少量光点以约 7 秒的周期缓慢移动，数值和滑块在非拖动变化时有短暂过渡。只有轨道区域按最高 24 帧/秒刷新；失去应用焦点或禁用控件时暂停光点。系统开启“减少动态效果”时，停止光点和数值/位置过渡。

## 验证范围

本次改变仅涉及原生界面。已编译并检查原生控件渲染；本机只替换设置应用，控制服务、桥接、逐聊天预算与全局配置不随此次 UI 部署改写。显示图片为静态预览，实际动态效果在打开的面板中查看。
