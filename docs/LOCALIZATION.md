# 中英语言设置

[English](en/LOCALIZATION.md) | **简体中文** · [首页](../README.zh-CN.md)

App 和安装器内可选择「自动（按时区）／中文／English」。选择保存在支持目录的 `language.json` 中，值为 `auto`、`zh` 或 `en`。切换立即生效，更新和重启后保留。

自动模式按系统时区名称判断：中国大陆、香港、澳门、台湾的时区和常见旧别名使用中文，其余使用英文。不按 UTC 偏移判断，新加坡和珀斯虽然也是 UTC+8，但默认英文。手动选择优先于时区变化。时区只在本机读取，不请求定位或进行网络查询。

语言变化会更新主窗口、菜单栏、原生菜单、图表说明、状态与错误提示、安装器以及 Hook stats。聊天名称、工具名称、模型标识、预算和已记录用量保持原值。

`src/locales/en.json` 是共享翻译表，以稳定中文文本为键、英文为值。参数使用 `{0}`、`{1}` 等占位符，两种语言的占位符必须一致。Swift 使用 `L()`；后端协议和持久化数据保持稳定，在显示状态消息时翻译。

构建会把同一翻译表放进 App 和安装器的资源目录；Stop hook 读取同一源表及语言选择。系统时区或语言选择变化时通知界面刷新；图表标签缓存包含语言标记，切换后重新整理。

测试覆盖 Swift／Node 的时区映射、手动优先、偏好损坏后的默认行为、参数保留、动态状态消息、中英切换、跨进程保存和翻译表完整性。
