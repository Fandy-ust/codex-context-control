# 0.19.1：以 Apple 为基准统一 Windows 操作

目标是切换系统后可以沿用同一套操作习惯。Apple 原生 SwiftUI/AppKit、Liquid Glass、系统材质、字体和可访问性不作替换；本版没有修改 `macos/` 源码。Windows 继续使用 Electron 和系统字体，匹配操作与信息层次。

## 保留的两项布局

- 左下角齿轮打开居中悬浮设置，保留现有分类与平台设置。
- 主页面左侧尽量留给聊天列表，保留可调整的侧栏宽度。

## 操作对照

| 操作 | Apple 参考 | Windows 0.19.1 |
| --- | --- | --- |
| 查看窗口 | `Chat.observedWindowTitle`、`windowConfirmed` | 区分上次/最近/不一致读回；只有连接、用量新鲜、版本与目标完全一致才显示已确认 |
| 调整预算 | `Controller`、`BudgetMath` | 每步 1K；主窗口最小 2K，压缩最小 1K；切换窗口保留比例锚点，遵守模型原生上限和拓展保护限制 |
| 预设分组 | `ContentView.rangeEditor` | 压缩一行含 80/85/90% 与最大；窗口一行含 200/400/800K 与最大，不支持的预设禁用 |
| 提交预算 | `ContentView`、`Controller.act` | 依次为预检、应用到此聊天/保存并接入后应用、原生压缩、停止自动应用；反馈保留在面板中 |
| 高级字段 | `BudgetMath.tokens` | 预留与必须保留量支持 16K、0.5M 或整数；无效输入不会悄悄转成 0 |
| 原生压缩 | Native confirmation dialog | Windows 原生确认框，明确请求压缩或取消，说明额度及结果长度的不确定性 |
| 上下文详情 | `ContextDetailsView` sheet | 居中详情弹层；完成、Esc、点击遮罩关闭；关闭后保留主页面未提交草稿与滚动位置 |
| 详情顺序 | `ContextSummaryView`、`ContextDetailsView` | 活跃上下文与缓存 → 费用估算 → 对话趋势 → 分类表 → 工具与统计口径 |
| 趋势选择 | `TimelineSelection`、`TimelineBucketDetails` | 悬停临时覆盖固定位置，点击固定新位置，移出恢复固定位置；默认展示最新区间的摘要 |
| 平滑与原始记录 | `ContextResponseChart` | 0–40 平滑滑条；按区间每页 20 条，点击记录显示明细；自动刷新尊重交互状态，不显示陈旧请求结果到新弹层 |
| 托盘预算 | `MenuBudgetDraft`、`MenuChatRow` | 悬停草稿、点击应用才保存；未改且已启用时禁用应用；支持离线聊天保存待接入，反馈排队/需压缩/待确认；取消和移出丢弃草稿 |

预算与统计数据仍来自共享核心，不修改后端预算策略。Windows 的纯界面规则集中在 `src/apple-ui.mjs`，模板集中在 `desktop/renderer/apple-view.mjs`，便于以后对照 Apple 的行为更新。已有加权动效与 Windows 全局快捷键保留，快捷键继续显示/隐藏主窗口。

## 交付范围

产品版本为 0.19.5；沿用同一提交的双平台构建工作流。按使用者要求，本轮只做编译、语法编译与打包，不启动应用、不执行单元/集成/视觉测试；实际交互和 DPI 效果由使用者在两端验收。

## 0.19.2 Windows 布局微调

上下文详情移到已保存预算同一行；移除预算框下方的常驻操作提示；底部操作统一尺寸，右侧依次为停止自动应用、应用到此聊天。默认窗口高度下收紧主页面间距，以便展示操作按钮。预算规则、确认反馈及 Apple 原生界面保持原有实现。

## 0.19.4 趋势断口连线

Windows 与 Apple 原生图表都在缺失区间的两侧有效数据点之间画直线。只改变图表连线，不插入虚构数据；区间均速、用量均值、EMA 重置、原始记录与缺失提示保持原有计算。Apple 有效区间内的原生插值、颜色和材质继续保留。

Windows 趋势图增加左侧数值刻度、线条及事件图例，以及跟随鼠标并在窗口边缘换向的数据浮层；下方固定摘要与原始记录继续保留。

## 0.19.5 拖动同步与渐进加速

预算填充、余量与滑块在同一帧更新，移除填充宽度过渡。粒子仍按压缩 80%、窗口 20% 加权，改用平方加速曲线；从左到右逐渐加速，右侧变化更明显。保持随机分布与漂移，拖动时只调整播放速率，不重置粒子相位；合并动画查询以减少样式计算。
