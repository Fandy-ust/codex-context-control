# 隐私与本地接口

[English](en/PRIVACY.md) | **简体中文** · [首页](../README.zh-CN.md)

本工具没有远端服务、遥测、外部字体、API key 管理或自己的模型调用。原 Codex 的网络行为、登录和模型调用仍由原运行时负责。

## 持久文件

默认目录是 `~/Library/Application Support/CodexContextControl`，权限为当前用户可读写。保存：

- 逐聊天预算及版本；
- 聊天标题/目录、模型、窗口、统计和状态；
- 安装设置、服务连接描述和 hook 配置备份；
- 本地服务日志。
- 菜单栏界面的进程与窗口状态（`ui-status.json`，不包含聊天正文）。

聊天标题和路径也是私人元数据。不要将这个目录提交到 GitHub。

桥接为了转发协议，必须经过原有请求/响应。它不会记录协议中的提示词、聊天正文、工具输出或加密推理。恢复会话所需的指令和配置仅在桥接内存中保留。集成测试检查指令正文不会进入控制服务状态文件。

元数据索引定期读取明确的 name 字段与 archived 标志，用于同步 Codex 中的名称和归档状态。旧版 SQLite 的 title 字段可能包含整条首个提示词，因此不读取该字段。未获得合适的客户端标题时显示目录名或聊天 ID；客户端传来的标题可能由消息生成，仍属于私人元数据。过长或多行标题不持久保存。

## 接口

项目侧栏只读本机 Codex 索引中的项目名称、根目录、排序和明确的聊天归属，并兼容 `.codex-global-state.json` 的项目相关字段。只在内存中保留相关项目字段，不改写原文件，不读取项目里的代码文件，也不连接远程项目主机。项目展开偏好保存在本工具自己的界面设置中。

控制通道使用本机 Unix socket。原生面板的 HTTP 接口只绑定 127.0.0.1，使用随机本地 Bearer token；连接文件权限为 0600。HTTP 拒绝缺少认证、非本机 Host 和带浏览器 Origin 的请求，不开放 CORS。

本机同一用户账户下的其他程序能读取该用户的本地文件，因此不将其视为对恶意同用户程序的隔离边界。服务不会接受任意命令执行请求。

## Hooks

安装前备份 hooks.json，仅增加本工具的定义，保留其他内容。卸载只移除匹配的本工具定义。使用文件内容检查避免覆盖安装期间的并发修改。不会修改 config.toml 或伪造 trust 状态。

Hook 无服务连接或不认识当前轮次时静默返回空结果，不阻止原聊天完成。父/子会话 ID 不明确时不猜测归属。

## 自动接入与系统权限

0.2 新增 `~/Library/LaunchAgents/io.github.codex-context-control.environment.plist`，在 GUI 登录时登记当前用户的 `CODEX_CLI_PATH`，随即退出。它不录音、不截屏、不请求辅助功能或麦克风权限。Codex 按系统正常方式启动；设置面板和 Node 不再负责启动桌面客户端。

该环境变量对当前用户会话可见，并非应用独占设置；其他读取它的程序会调用透传包装器。已有其他自定义值时拒绝覆盖。卸载停止本项目的登记任务，仅当当前值仍等于本项目路径时恢复原值；保留后来由其他工具修改的值。恢复信息保存在私有安装目录的 `automatic-startup.json`。

本工具不会自动修改、重置或扩展 macOS TCC 隐私授权。旧启动方式遗留的 Node 权限记录不会自动删除。

## 尚未覆盖

多用户共享安装、远程宿主、云端线程、多个同时拥有同一聊天的独立运行时，以及任意版本的内核估算差异，不属于 0.5.2 的完整支持范围。

fork 继承额外保存直接父对话 ID 和父预算修订号，用来说明副本来源；不为继承读取或复制聊天正文。

## 可选的上下文详情

打开详情页后，独立工作线程只读本机 SQLite 索引和所选聊天的 JSONL 历史；分支按记录的字节、条目边界继承，压缩按替换历史重置。为重建分类，正文与不透明字段会短暂存在该工作线程内存中；不透明内容不解码、不分词，也不返回给界面。工作线程会复用；超时或闲置 60 秒后退出并释放缓存。

服务只返回分类数量、token 估算和响应指标。最多缓存 12 个聊天的聚合结果；自动刷新检查文件版本，只有变化时重算。工作线程另外最多暂存 4 个解析过的日志片段、合计 64 MiB 源数据，以及 20,000 个内容哈希对应的 token 数。token 计数缓存不再存一份正文，所有这些缓存仅在内存中；不持久化统计正文或新增遥测。响应指标包含响应/轮次 ID、时间、用量、缓存、计时和白名单内模型配置，不含对话文本、工具输出或模型内部推理。

认证与其他本地接口相同；接口只接受已知聊天 ID，不接受任意文件路径。读入有大小、递归深度、路径和分支边界限制。统计最多同时占用两个工作线程，超时 25 秒，不阻塞预算控制通道。分词器及词表随安装打包，分析不联网。

## 费用估算

费用只使用已提取的响应 token 数、模型和配置档位，结合随安装打包的官方价格快照在本机计算。不会读取 API key、调用模型、查询账户账单或自动连接价格服务；新增返回值仅包含费用分类与汇总。

原生日志的增量路径依赖其追加写入语义；文件替换、缩小或同大小重写自动失效。手动刷新完整重验文件，保留按内容哈希校验的分词计数。模型目录只按文件版本缓存公开的模型能力元数据。并行上限固定为两个工作线程，不会随刷新次数增长。

语言偏好保存在本机 `language.json`。自动语言只读取系统时区名称，不请求定位、不进行网络查询，也不记录时区历史。聊天名称和用户内容不翻译。

## 更新检查与对话缓存

自动更新检查只向本项目公开 GitHub 仓库请求版本信息，点击安装后才下载文件，不上传聊天内容或凭据。本地对话缓存保存文件指纹、读取位置、模型、最近用量和窗口容量，不保存聊天正文。首次只读取有上限的 256 KiB 文件尾部，之后只处理完整的追加记录；未变化的文件直接复用缓存。

额度指示通过短时的官方 Codex app-server 会话读取账户额度，不打开聊天、不请求模型生成。仅在内存中缓存额度百分比、周期和重置时间，每五分钟刷新；登录凭据仍由官方运行时处理。

官方接口提供具体 credit 余额时，会在额度菜单中显示，并仅缓存在内存里；没有数值时不再显示泛化的“额外额度可用”。
