# Windows UI 验收清单

实现分支：`codex/windows-adaptation`。这些是交给使用者的视觉与交互检查；自动加载检查已覆盖主窗口、托盘、默认值页面与统计图，但不代替这份人工验收。

## 开始

先用 `npm run dev:win -- --demo` 查看合成数据 UI。连接真实聊天前，按 [Windows 安装说明](INSTALL_WINDOWS.md) 安装，并在工作结束后完整退出、正常重开 Codex。

本次开发没有重启当前 Codex，也没有自动修改真实 `CODEX_CLI_PATH`。首次安装后的正常桌面接入需要在使用者环境激活后确认；如果无法连接，提供「诊断」中的版本、连接数和状态即可，不需要发送聊天正文或凭据。

## 外观与布局

- [ ] 主窗口保留深色背景、灰色圆角卡片、细边框、低对比选中行；品牌图标正确。
- [ ] 侧栏聊天名称、模型、状态、用量、已保存预算和草稿容易区分，长标题没有挤坏按钮。
- [ ] 分隔线可拖动调整侧栏宽度，窗口变窄时不遮挡内容，键盘可调整分隔线。
- [ ] 双滑块的蓝色压缩点、白色窗口点、灰色余量段、预设和高级设置与原版含义一致。
- [ ] MAX CONTEXT 只改变对应进度条，卡片背景保持深色；动画没有闪烁或突然重置。
- [ ] 中文、English 和自动语言切换正常，聊天名称保持原文。

## 托盘

- [ ] 右下角或折叠区能找到圆环入口；左键展开/关闭，右键菜单可用。
- [ ] 弹窗贴近入口并处于屏幕工作区内；双屏、不同 DPI、负坐标显示器没有越界。
- [ ] 正在运行聊天排在前面，近期聊天与运行中聊天分开；缺失用量显示待观测，旧读回有标识。
- [ ] 悬停行进入单滑块编辑，鼠标移出、取消或关闭面板丢弃未保存修改。
- [ ] 拖动期间不会跳到另一行；松手保留最终 1K 值，点击应用才能提交。
- [ ] Esc 和外部点击关闭小面板；拖动期间不误关；关闭主窗口后托盘保留。
- [ ] 在方便时重启 Explorer，确认图标恢复。明/暗任务栏均有足够对比。

## 主窗口与图表

- [ ] 点击、拖动、−/＋和方向键都按 1K 调节；两点靠近时能通过数值按钮选择目标。
- [ ] 调整窗口保持压缩比例，取消/重载恢复已保存值；刷新不会覆盖正在编辑的草稿。
- [ ] 全局默认可保存，也能复制当前聊天设置；上下文拓展显示等待重启与实际生效状态。
- [ ] 统计分类、工具次数、费用说明、快照时间、推理生成统计和缺失值说明都能展开。
- [ ] 趋势平滑度 0–40 可选择；悬停只移动游标，点击可固定，Esc 取消固定，原始记录可翻页。
- [ ] 长聊天图表和聊天切换没有明显卡顿；窗口隐藏或失焦后动效停止，系统减少动态效果生效。

## 系统可访问性

- [ ] 在 100%、125%、150%、200% 缩放下文字、滑块和按钮没有遮挡。
- [ ] Tab 顺序合理，方向键、Enter、Esc 可完成主要操作，Narrator 能分别读出两个滑条的名称和值。
- [ ] 系统高对比模式下仍能识别焦点、控件边界和状态。

## 激活后确认

- [ ] 正常打开 Codex 后托盘能自动出现，诊断显示桥接已连接。
- [ ] 一个正常请求后，实际窗口与确认状态有读回；单纯保存或收到接口成功不显示“窗口已确认”。
- [ ] 打开真实聊天后的工具、取消和生成流程与原使用方式一致。

反馈时记录：使用的构建版本、屏幕缩放、界面语言、操作步骤、预期与实际表现。截图中遮掉真实聊天标题及其他私人内容。
