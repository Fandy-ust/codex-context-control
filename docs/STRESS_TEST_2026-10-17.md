# 压力测试与性能修复 · 2026-10-17

版本 0.15.5；Apple Silicon macOS，随包 Node 22.23.3。测试在隔离目录、模拟服务与独立原生窗口中运行，未对用户聊天执行压力写入，未发起付费模型请求。真实聊天只用于读取统计性能。

## 发现与修复

1. **异常 IPC 可终止服务**：`null` 等消息在异步入口抛出未捕获错误。现拒绝错误信封，仅关闭错误连接；未收到换行的帧也限制在 1 MiB 内。新增畸形 JSON、原始值、拆分 UTF-8、超长无换行和其他连接继续工作测试。
2. **纯事件图表越界崩溃**：121 条事件、0 次响应等非整除组合会产生空区间，再访问 `end-1`。现在按实际分组大小计算区间数。覆盖边界数量、500 组混合组合以及 100,000 条记录。
3. **数据库升级后可能读旧库**：元数据索引用文字排序，`state_9` 排在 `state_10` 前。改为数字版本排序，并验证名称读取自较新库。
4. **大历史缓存反复失效**：约 68 MB 的真实继承历史超过 64 MiB 解析缓存预算，导致内容没变也重读。新增小型依赖记录，检查文件标识、大小、修改/变更时间与数据库路径；不变则复用统计结果。追加、替换、索引换路径和手动强制刷新仍会重算。
5. **暂时的版本检查失败被永久缓存**：短暂失败后即使运行时恢复，原逻辑仍可能一直报不可用。失败结果现在有重试间隔；成功结果仍按文件指纹缓存，可选修复包的暂时检查失败也可恢复。
6. **MAX 动画后台消耗**：紫色条补上主面板不活跃或控制禁用时的暂停，与普通进度条保持一致。

统计服务同时增加结果标识：未变化的结果不再跨 worker 重复复制，HTTP 层复用相同结果的序列化文本。保留最多 2 个 worker、8 个待处理聊天、12 项结果缓存和空闲释放，不通过增加 CPU 并发或解析缓存上限换取速度。

## 性能测量

真实聊天前后两次只读采样（期间聊天仍增长，约 68 MB，934→938 次响应）：未变化读取原先 267–348 ms，修复后 0.81–0.89 ms；修复后的两次读取没有新增历史字节读取，且复用了主进程结果对象。手动强制重读仍约 185 ms。冷启动、系统文件缓存和负载不同，不把冷启动采样换算为优化比例。

合成负载独立采样：24 并发保存 P95 14.03 ms，最慢 28.13 ms；统计热读 P95 0.13 ms；1,000 条观测合并为 1 次落盘。整体 4021 ms，压力进程含 worker 与比对器的峰值 RSS 589.6 MiB，事件循环 P99 19.32 ms。该内存值不是 App 常驻内存。
