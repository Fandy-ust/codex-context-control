## 本次更新 / Highlights

- 新增多账号登录管理：官方浏览器授权、实验性应用内授权、保存当前登录、账号命名及移除本机登录；凭据在本机加密保存，不参与云同步。
- 支持确认后切换账号并重新打开 Codex。修复暂停队列后仍被拦截的问题；仍有会话运行时，可选择“强制停止并切换”。
- 账号管理卡片增加 Credits、5 小时及每周额度，保留各自的重置时间；侧栏名称更清晰，非当前账号增加快速切换按钮。
- 更新 context-manager 技能，支持指定聊天添加任务、调整顺序、管理额度监视及暂停/恢复队列。
- 新任务默认跟随聊天的模型和思考预算；读取不到思考预算时使用 Medium。
- 任务卡片支持拖动排序和落点提示，执行中任务保持固定。
- 队列遇到上下文阈值时自动请求压缩，确认完成并取得新用量后继续，避免重复派发。
- 额度启动预约支持“仅明天一次”与“每天重复”，按本机时间执行；显示下次时间，错过时跳过而不集中补发。
- Windows 与 macOS 同步更新。安装后重新打开 Codex 以加载新运行时；已失败的旧任务需手动重试。账号切换及应用内授权属于实验功能。

Adds encrypted local account switching, per-account quota cards and quick switching, richer queue skills, inherited reasoning settings, drag reordering, automatic context compaction, and daily or tomorrow-only activation schedules.
