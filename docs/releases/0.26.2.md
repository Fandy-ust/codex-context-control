# 0.26.2

- Add native Windows and macOS notifications for confirmed 5-hour and weekly Codex quota resets. Resets observed within twenty seconds are combined into one notification.
- Enable or disable reminders with the “Quota reset notifications” switch in Quota activation settings. Notifications are independent of automatic message probes and are enabled by default.
- First observations, account changes, stale readings and expired countdowns without reset evidence do not generate alerts. Delivery IDs are persisted to prevent repeats after restarts; notices older than ten minutes are discarded.
- Keep Context Manager running in the system tray/menu bar and allow its notifications in system settings. macOS requests notification permission; Windows uses the installed Start-menu application identity. System Focus/Do Not Disturb settings may suppress banners.
- The normal LZMA2 installer and existing in-place upgrade path are unchanged.

Native macOS notification presentation requires validation on macOS.
