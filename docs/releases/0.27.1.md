# 0.27.1 — 队列技能、拖动排序与自动压缩

- context-manager 技能支持指定聊天添加任务、调整完整任务顺序、暂停/恢复全局额度监视，并说明如何保留现有额度设置及确认停止结果。本机安装副本与仓库内技能同步。
- 新任务默认跟随目标聊天的模型和已观测的思考预算。无法读取思考预算时使用 Medium；明确选择覆盖继承值。模型不支持该默认值时使用其支持的默认值。
- Windows 任务卡片增加拖动柄、落点提示，并在拖动期间保留页面。macOS 使用原生拖放。保留隐藏历史、附件和设置；执行中任务的位置固定。
- 队列启动因上下文接近压缩阈值被拦截时，自动请求原生压缩。确认完成并取得新用量后，重新检查并仅发送一次原任务。压缩失败、未取得新用量、压缩后仍超限或用户停止准备时，不发送任务。

已经失败的旧任务不会静默重启；在任务卡片点击“重试”并恢复该队列即可使用新流程。安装后重新打开 Codex，以加载更新后的队列运行时。

Windows 通过模拟界面与隔离测试验证，不在当前真实聊天中执行压缩或派发任务。macOS 源码已同步，在 Windows 环境未验证原生编译与运行。
