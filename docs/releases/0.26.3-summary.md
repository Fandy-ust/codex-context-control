## 关键更新 / Highlights

- **Windows LZMA2 安装包**：单个 EXE，体积约减少 29%，沿用普通版目录和覆盖升级方式。
- **修复接入进程残留**：Windows/macOS 共用核心在客户端退出时清理所属运行时，减少旧、新进程重复登记聊天。
- **额度启动与提醒**：周重置探测、一次性预约、起床前提前量建议，以及 5 小时／每周／同时重置的系统通知。
- **设置与大历史**：滑动开关、更准确的连接冲突提示，保留大聊天历史分段读取。

Windows and macOS builds, automated tests, installer checks and update validation passed in GitHub Actions. This release keeps the normal installation and existing user data.

升级后请在任务结束时完整退出并重开 Codex；已在内存中的旧版接入进程不会自动获得新的退出清理逻辑。
