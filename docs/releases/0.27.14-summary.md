## 本次更新 / Changes

- 账号授权期间可复制授权链接，方便在其他浏览器中继续；浏览器打开失败时保留授权请求。
- 修复内建登录的验证子页面拦截、弹窗会话和回调问题；增加重新载入、返回及浏览器接续操作。
- **Google 登录兼容性：**Google 可能限制嵌入式浏览器，即使页面能打开也不代表后续授权一定成功。遇到 JavaScript/不支持浏览器提示时，请使用系统浏览器，或复制授权链接到支持的浏览器。

Authorization links can now be copied to another browser. Embedded sign-in keeps verification frames and popup sessions intact and provides recovery actions. Google may still reject embedded browsers; use browser sign-in or copy the authorization link when that happens.
