# 0.22.4（本地版本）

- 新增每消耗 1% 额度对应的本机预估 API 费用（USD / 1%）图，5hr 与 Weekly 分别计算，默认显示费用比例。累计变化至少 1% 且区间费用完整才生成点，悬浮详情包含费用、额度变化和起止时间。
- 图表中间切换周期，右侧选择周期重叠，默认最近 6 个实际观测周期，可选 3 / 6 / 12 个；各条线按周期开始对齐。右下角两个时间框可筛选比较范围，保留单周期模式及 Credits 余额图。
- 扩大任务输入框，附件在框内排列；底部“＋”菜单插入图片或文件，右侧圆形向上箭头提交任务，没有麦克风或 Hook 按钮。
- 模型和思考程度默认显示为一行，点击弹出带细线闪电图标、模型菜单与分档滑杆的选择面板。
- 每项任务可设置审批权限：默认沿用当前聊天，也可选择 Ask for approval、Approve for me 或 Full access；通过原生 turn/start 的 approvalPolicy、approvalsReviewer、sandboxPolicy 参数执行，不修改用户全局配置。
- 修复上下文预算已保存却阻止队列启动：相同窗口与压缩配置只同步版本号；缺少新用量记录时允许和手动发送相同的观测轮次，不跳过不安全预算预检。预算重新加载失败不会伪装为已应用。
- 队列接入协议升级到 4，避免旧桥接程序忽略新权限设置。使用新队列功能需完整退出并重开 Codex，让新桥接生效。

Windows 与 macOS 源码同步，Mac 使用原生 SwiftUI Menu、Popover、Slider、Toggle 与 DatePicker。队列仍为 EXP 实验性功能。本轮不运行 macOS 构建或测试；仅本地构建，不上传发布。
