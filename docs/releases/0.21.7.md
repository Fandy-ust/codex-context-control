# 0.21.7

Both platforms now show a bordered **Compact now** button beside Apply. It calls the existing native `thread/compact/start` operation instead of submitting chat text. Only a uniquely connected, idle, directly usable chat is eligible; the bridge also rejects requests while a turn is being submitted or a reload/compaction is in progress. Repeated clicks cannot launch concurrent compactions. New input arriving during compaction waits for completion; failures reject that input rather than silently sending it.

## Recent macOS parity audit

| Feature | Windows | macOS |
| --- | --- | --- |
| Compact projects, unchanged Recent spacing and quota footer | CSS | SwiftUI layout |
| Version before Settings | Implemented | Implemented |
| Analytics uses the app content area and keeps bordered Back visible | Fixed header | Native safe-area inset |
| Prediction and usage analysis on the same page | Implemented | Implemented |
| Model/source/pool/time filters | Shared report API | Same report API |
| Simple / Advanced modes and conditional model comparisons | Shared chart selection | Same chart selection |
| Cost heatmap / line, day/week/month/year, historical dates and exact ranges | Implemented | Implemented |
| Plain-language fit interpretation, reliability and collapsed technical details | Shared report fields | Same fields |
| Guide text behind title info control | Popup | Native popover |
| Hover metric cards and dismiss on scrolling | DOM card | Native material card |
| Conversation chart scroll/hover handling | Passive wheel and deferred refresh | Native scrolling and deferred selection/refresh |
| Budget handle dragging | Pointer hit targets and grab offset | Native geometry and grab offset |

The audit found three small gaps, now addressed: native default custom ranges ended at the current instant rather than the next midnight and did not follow a newly selected historical day; old native hover data could remain after filters changed; native point details omitted the Token / pp value shown on Windows. Cost range defaults now span the selected local day, and hover state clears when its data changes.

macOS intentionally retains native SwiftUI controls, Swift Charts, popovers and material cards. Its tooltip position and heatmap cell rendering differ visually. Both apps share the daemon, analytics, pricing and prediction calculations; no second native implementation of those calculations is required. Windows cannot compile or execute SwiftUI, so source coverage is not a claim of successful Mac runtime validation.
