# 0.27.9 — One-click account switching

- Clicking a saved account switch in settings or the quota sidebar pauses queues, stops Codex/CLI sessions, switches credentials, and reopens the desktop app without extra confirmation dialogs.
- Keep credential identity validation and refuse to replace credentials if sessions cannot be stopped.
- Both macOS and Windows use the same switching behavior and shared version.
- Use the 0.27.9 installer when updating from 0.27.8; the previous custom build reused 0.27.8 and could be confused with the upstream installer.
