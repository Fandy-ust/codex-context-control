# 0.27.3

See [release highlights](0.27.3-summary.md) for user-facing changes.

Automatic account handoff is off by default and uses only saved local file-backed logins. Candidates need fresh live quota checks. All managed chats must be idle; unmanaged or older runtimes block automatic switching. The manager suspends dispatch, verifies process exit, switches credentials, reopens the desktop and verifies the selected identity before continuing. No candidate means the queue remains waiting. Manual pauses and unrelated live work are preserved.

Cloud account summaries are encrypted display snapshots with their original observation timestamps. Local names take precedence. Remote snapshots do not authorize switching or dispatch; authentication tokens and the credential vault are not synchronized.

Automatic retries default on for automatically resumed tasks and can be disabled per task or in defaults. The fixed cumulative schedule survives restarts. Missed slots are skipped, not replayed in a burst. Known failures and quota waits may retry; unknown submission outcomes, manual stops and interrupted restarts require manual handling. Eight unsuccessful attempts retain the task for inspection.

Validation covers shared scheduling, account guards, credential rotation, summary allowlists, CLI/API behavior and packaged desktop UI. Native macOS compilation and UI validation run in GitHub Actions; real account switching is not performed by automated tests.
