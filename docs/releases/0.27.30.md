# Context Manager 0.27.30

Calculate retained historical-reasoning estimates before applying a context window or compaction threshold, then load both with runtime accounting headroom at a safe boundary. The user target remains bounded by native model limits or the optional 920K extension. Agent summaries separate real targets/headroom from runtime accounting values. Cold resumes include the estimate before configuration is applied; the old manual compensation switch remains retired.

One-shot handoffs can use fresh extra Credits when available, honoring the existing Credits-stop trigger. Ordinary queue reserves are preserved. Readiness reports the funding source and protection reason.

Both platforms share these behaviors. macOS continues to execute the unchanged official Codex under the desktop app, with the Node bridge as a child; no modified runtime, new monitoring server, signature-check relaxation or Chrome-permission change is introduced. Boundary accounting is an estimate, not a guarantee against mid-turn native compaction. Normal Codex reopening is required to load the new bridge.
