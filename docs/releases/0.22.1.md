# 0.22.1 — EXP 实验性任务队列更新

本次为本地开发版本，尚未上传、触发远程构建或发布 Release。

- 修复必须先点击 Codex 目标聊天窗口才能启动任务的问题：通过唯一兼容的接入桥后台加载聊天，忙碌时等待，不切换用户页面。
- 修复旧版接入桥返回“不支持的运行时操作”却只显示“任务提交未确认”的问题。发现旧协议时明确提示完整退出并重开 Codex，不提交任务。
- 开始检测改为开关，支持明确接管当前执行轮次；队列完成自动关闭，无任务不额外监视或阻止睡眠。
- 队列改为紧凑任务卡片，主聊天最多展示两项。展示状态、保留比例与释放梯度摘要，可删除、重试、停止和排序。
- 点击任务打开统一编辑器，设置完整提示词、附件、模型、思考程度、独立额度、恢复策略和最多三个释放梯度。
- 当前聊天的限额作为新任务默认值；现有任务保存自己的配置，切换任务时立即使用下一项的额度保护。
- 图片通过原生 localImage 输入；普通文件作为本地路径加入任务上下文，启动前检查可读性。文件选择器与 Windows 文件拖放支持多个附件。
- 从真实模型目录提供模型与思考程度选项，提交前再次检查模型能力；保留聊天原有权限、工作目录和其他执行参数。
- Windows 沿用现有界面组件与风格，macOS 同步改为原生 SwiftUI 开关、任务卡片、编辑器、文件选择器和三梯度设置；共用队列引擎与协议。
- 任务失败时停止队列，核对、重试或删除后继续，避免自动跳过失败工作。

## 验证与边界

本地共享逻辑/Windows 测试：271 项，243 通过，28 跳过，0 失败。Windows UI 冒烟验证通过，包括任务卡片、编辑控件、固定返回、排序、统一关闭、滑块和图表滚动。

按要求未执行 macOS 构建或运行测试；macOS 源码同步修改，不代表已完成原生运行验证。

本次使用合成聊天、临时服务与模拟运行时验证，没有向真实 Codex 聊天发送任务。更新接入程序后须完整退出并重开 Codex 一次，加载支持 0.22.1 队列协议的桥；之后开启队列不需点击目标聊天窗口。

官方队列暂停/保留功能仅完成研究，尚未集成。见 [研究记录](../research/official-queue-0.22.1.md)。
