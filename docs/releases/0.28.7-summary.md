### 更新内容

- 「关于与维护」可直接从 OpenAI 官方文档更新模型价格，并列出新增或费率变化的模型。缺少价格时，每天最多自动尝试一次。
- 可手动刷新已接入的 Codex 模型列表和推理档位。
- 「账户额度」可选 API 分档或无梯度 Standard 计价，默认保留 API 分档。该选项用于聊天费用和额度分析中的费用估算。

### What's new

- Update prices directly from OpenAI's documentation and see which models were added or repriced. Automatic attempts are limited to once per day when prices are missing.
- Refresh the connected Codex model list and reasoning options from Maintenance.
- Choose API pricing bands or flat Standard rates for chat and quota cost estimates. API pricing bands remain the default.
