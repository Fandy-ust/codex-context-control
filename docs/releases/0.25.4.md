# 0.25.4

Long chats whose history exceeds 128 MiB can now load context statistics. The shared Windows/macOS controller reads records in bounded chunks and discards unused payloads before caching statistics, while preserving fork boundaries and incomplete live-record handling. Original chat history files are not modified.

历史文件超过 128 MiB 的长聊天现在可以读取上下文统计。Windows 和 macOS 共用的控制器改为分块读取，逐条提取统计所需内容，并保留分支边界与未完成记录校验。原始聊天记录不作修改。
