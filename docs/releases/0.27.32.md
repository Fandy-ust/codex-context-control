# Context Manager 0.27.32

One-shot handoff registration now includes an explicit agentInstruction: save progress, end the current turn, and wait for the next message. The app waits for exact source completion and readiness before sending one same-chat checkpoint message. Replayed completed receipts request inspection rather than another pause.

The shared skill explains why turn boundaries are necessary, how to explore headroom, choose soft adjustment versus urgent handoff, interpret receipts, wait for necessary user decisions without scheduling, and verify the resumed execution. Synchronous interview answers do not themselves hot-reload a window. No new plugin, runtime, monitoring loop or UI panel is added. Both platforms share this behavior.
