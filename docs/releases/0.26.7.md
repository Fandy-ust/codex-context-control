# 0.26.7 — 多账号额度与账号管理

- 在“设置 → 云同步 → 账号与设备”自定义账号简称；留空使用邮箱。
- 每个账号都有独立的“在侧栏显示额度”开关，立即保存，不影响统计或同步选择。可显示多个账号或全部隐藏。
- 侧栏逐行显示所选账号的 Credits、5 小时及每周额度，当前登录账号优先。使用小号标签、较淡的非当前账号组件颜色，不增加遮罩或卡片边框。
- 未登录账号保留最近一次额度与真实重置时间，重启后仍可查看；倒计时到期显示等待刷新，不推算未来重置周期。
- 通过确认按钮删除账号及其全部本机统计，包括额度缓存、Credits 基准、额度历史、Token/费用记录和已下载的同步数据。其他账号保留；日志重扫和同步导入不会恢复被删除的旧统计。
- 删除不会退出 Codex，不删除原始聊天、其他设备或云端文件。当前账号再次检测后会记录新数据。
- Windows 与 macOS 共用版本和数据逻辑，macOS 使用原生账号控件与侧栏。

验证：本机回归测试 417 项，374 通过、43 按平台或实机依赖跳过、0 失败；Windows Electron 界面测试验证账号命名、显示开关保存、多账号排序、重置时间和非当前账号颜色。发布 Actions 另外执行 Windows 安装包及双语言界面检查，以及 macOS 原生编译、安装和 DMG 校验，两端全部通过后一起公开发布。
