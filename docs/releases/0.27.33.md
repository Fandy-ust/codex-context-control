# Context Manager 0.27.33

A running controller could retain its working directory inside a code directory that installation atomically renamed and removed. Its next Node worker then failed during bootstrap with ENOENT uv_cwd, affecting statistics for every chat. The generic worker error concealed that cause.

The controller now launches from persistent app data on both platforms, and its direct entry point also selects that stable working directory. Replacement of code no longer invalidates the cwd inherited by statistics/analytics workers. A real-service regression removes the original launch directory and requests statistics afterward. No history, context budget, Chrome permission, official Codex binary or launch ancestry is changed.
