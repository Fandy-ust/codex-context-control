# 0.22.3（本地版本）

- 额度读取改为每 10 秒检查一次，同一分钟内观测到的每次百分比与 Credits 变化分别保存；没有变化的读数合并，不补造未观测到的百分比。
- 额度走势有一个观测点即可显示。默认横轴覆盖当前完整重置周期：5 小时或 Weekly，可选择开始、结束日期和时间查看历史。
- 新增 Credits 余额和走势，与百分比额度分开显示。Credits 不假定会随订阅额度重置；默认借用当前额度周期的时间范围，充值和长时间断档分段显示。
- 日期范围收为图表卡片右下角的两个紧凑输入框，修改后自动应用；移除重复说明，保留小型重置入口与图表提示。
- 调细图表折线、缩小数据点，保留悬浮查看的命中范围。
- 队列未完成任务保持执行顺序并显示在前，已完成任务按完成时间倒序显示在后。完成满 12 小时自动移入可展开的归档任务，保留记录；待执行、失败和中断任务不会因时间归档。
- Windows 与 macOS 共用采集、时间范围和队列归档逻辑；Mac 使用原生 SwiftUI 日期选择器与分段控件。队列仍属 EXP 实验性功能。

仅本地构建，不上传或发布。macOS 源码同步，本轮不运行 macOS 构建或测试。
