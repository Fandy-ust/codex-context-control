## 0.23.0 · 提前压缩补偿与 Agent 队列 CLI

- Mac 与 Windows 新增独立的「提前压缩补偿（实验性）」开关，默认关闭。根据有效历史的推理长度动态预留运行时空间，保持官方二进制不变。
- Codex 可能显示更大的上下文窗口，目标容量以 Context Manager 为准；历史不足或接近上限时明确显示未补偿。它不是对所有路由与极端长度的完整修复保证。
- 补偿覆盖普通提交、可确认的完整 fork、恢复聊天和任务队列；关闭后自动应用中的聊天下轮恢复原窗口。
- 新增供 agent 调用的队列 CLI：查询聊天／队列、添加和编辑任务、调整额度配置、排序、启动、暂停、重试及停止指定任务。使用同一套队列服务与额度保护。
- CLI 默认输出 JSON，支持文件／stdin 输入、revision 冲突检测和添加任务的 request ID 去重。安装器附带使用内置 Node 的独立入口，无需另装运行环境。
- 包含此前 0.22.5 的任务编辑器、附件与额度分析改进。两端保持相同版本；Windows 的真实 Codex 接入与 Computer Use 仍需实机验收。
