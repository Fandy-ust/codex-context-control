# 0.27.2 — 每日额度启动预约

预约改为“选择几点”并选择方式：

- 不预约：保留时间选择，不安排触发。
- 仅明天一次：固定在明天所选的本机时间执行一次，然后自动结束预约。
- 每天重复：从下一个所选时间开始，之后每天按本机时间执行；跨日和夏令时按日历计算。

显示已保存的下次预约时间。预约在发送前持久化，重启不重复执行已消费的时段；错过超过 15 分钟跳过该次，每日预约仍保留后续日期。休眠多天后只考虑最近一个时段，不集中补发。停止并取消预约会取消每日重复。

保留原有额度有效性检查、已启动周期不额外发送、每次最多三次尝试及读回确认。电脑仍需保持唤醒、管理服务运行。既有单次时间戳保持有效，重新保存时使用新的预约方式。

Windows 使用打包模拟界面与隔离测试验证；未创建真实账号的预约或发送真实探测。macOS 界面同步修改，在 Windows 环境未验证原生编译与运行。
