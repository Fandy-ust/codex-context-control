## 关键更新 / Highlights

- 多账号额度可同时堆叠显示，当前账号优先；每个账号可以单独隐藏额度。
- 为账号自定义简称，默认使用邮箱；未登录账号保留最后观测的额度与真实重置时间。
- 确认后可清理指定账号的本机额度和统计数据，其他账号的记录保持不变。
- 新增 Windows 与 macOS 对应界面，并保留各平台原生控件和颜色样式。

Show and name multiple accounts in the sidebar, hide quota per account, retain observed reset times, and delete one account’s local statistics after confirmation.
