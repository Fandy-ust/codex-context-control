# 1.0.0 — LZMA2 Windows installer research

This is an unpublished research branch. Windows Setup now embeds the full payload as a stored ZIP wrapped in LZMA2. It embeds the checksum-pinned 7zr 26.05 decoder, so installation remains offline and self-contained. The decoder writes only to stdout; the existing ZIP reader validates each destination. The decoder, compressed archive and intermediate ZIP are removed with the temporary installation directory, including on failure.

The UI, Electron, Node.js, application logic, language resources and tokenizer are retained. Installed size is not reduced. Decoding uses a 64 MiB dictionary; the intermediate ZIP temporarily uses roughly one additional payload's worth of disk space. Decoded ZIP size is limited to 2 GiB and decoding has a three-minute timeout.

Online updates remain standard ZIP, preserving compatibility with existing installations. Windows and macOS share version 1.0.0; macOS keeps its native UI and existing DMG packaging. Native macOS validation requires a Mac.

Build on Windows with `npm ci` then `npm run build:win`. The first build downloads the pinned public-domain decoder from the official 7-Zip GitHub release into `build/tools/`; cached bytes are revalidated on every use. For offline builds, set `CONTEXT_CONTROL_7ZR` to the identical pinned executable. Hash mismatches fail the build rather than silently falling back to a different compressor.

Validation: `npm run test:ci`, `npm run test:win:setup`, `npm run package:win:update`, `npm run test:win:update`, and packaged UI smoke tests in both languages. Installer regression tests cover both ZIP and LZMA2, byte preservation, corrupt archives, decoder tampering, path traversal, child-process failures and temporary cleanup.

Windows 安装包改用 LZMA2 压缩，解压器内嵌，无需用户安装 7-Zip。界面、功能与运行时完整保留，安装后的体积不变。旧版在线更新仍使用兼容的 ZIP。此分支尚未发布；macOS 沿用原有界面与打包方式，并共用 1.0.0 版本号。

## Local Windows validation — 2026-10-23

- Full suite: 334 passed, 38 skipped for platform/environment prerequisites, zero failures. Subsequent installer regressions also cover tampering with the embedded decoder itself.
- Actual standalone ZIP 0.25.4 → LZMA2 1.0.0 upgrade: preserved saved budgets, language, shortcuts and unknown settings. Verified all 223 installed payload files against their SHA-256 manifest and the build input.
- Compared 170 UI/core/runtime files against the previous installed payload. Binary files are identical; 26 text files differ only in Git LF/CRLF checkout conversion. No UI or business-logic source changes were made for LZMA2.
- Packaged English and Chinese UI smoke tests passed, including quota charts, cloud settings, sliders, task queue/composer, appearance, main/tray windows and shortcut recording/focus; native shortcut probe passed.
- Standalone install, repeat install, launcher/CLI/hook, service replacement, upgrade, uninstall, data retention and temporary cleanup passed in isolated directories. Standard ZIP OTA installation and corruption rejection passed.
- The complete Setup is approximately 129 MB, compared with 182.4 MB for the local 0.25.4 ZIP Setup (about 29% smaller, decimal MB). The earlier 114.8 MB experiment was a direct 7z payload, not an installer with the retained ZIP validation layer.
- macOS native execution and Windows ARM64 were not tested on this Windows x64 host. Existing macOS packaging is unchanged and consumes the shared 1.0.0 version.

To repeat the historical upgrade check, set `CONTEXT_CONTROL_PREVIOUS_SETUP` to the 0.25.4 Setup and `CONTEXT_CONTROL_CURRENT_SETUP` to the 1.0.0 Setup, then run `node --test test/windows-major-upgrade.test.mjs` after building. Without these paths the test is explicitly skipped.
