### Codex 数据保护 / Codex data protection

- Windows 与 macOS 新增 Codex 备份历史、手动备份及恢复；支持关闭 Codex、恢复并重新打开。
- 自动备份采用增量压缩和日、周、月保留策略，并在恢复前验证数据。管理器配置写入也增加了持久化和损坏恢复保护。
- Both platforms add backup history, manual backup and restore, including an optional close, restore and reopen flow. Incremental backups use calendar retention and are validated before restoration.
