## 0.24.2

- 新增「账号与设备」：自动识别 Codex 账号，切换登录后保留各账号的费用与 Token 历史，套餐或模型变化不拆分账号。
- 支持当前账号、全部账号、所选账号统计，以及按设备勾选；取消统计不删除历史。
- 每个账号可独立暂停同步，已下载数据仍可查看；重新开启后补齐新增统计。
- 通过加密目录发现其他设备和账号，设备名称可编辑；所有账号可共用同一私有仓库和同步密钥。
- 未归属旧记录默认不混入账号，可勾选「显示未归属历史（不上传）」查看；只有明确确认后才归入当前账号。
- Windows 与 macOS 同步更新。建议所有设备都升级到 0.24.2；旧版数据可读取，但旧版不会发布多账号发现目录。
- 不上传账号邮箱、登录凭据或聊天内容。其他设备发现的账号使用匿名编号，本机登录过的账号显示本机账号信息。

统计筛选和暂停同步仅在当前设备生效，不删除 GitHub 上的数据。设备旁的时间表示最近一次发布数据快照的时间。
