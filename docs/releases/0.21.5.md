# 0.21.5

Mac 与 Windows 同步更新费用日历和用量分析。

费用日历可选择历史日期；日视图展示该日期的小时。支持自定义开始与结束日期/时间，使用本机时区，包含开始时刻，不包含结束时刻，最长 366 天。选择自定义范围后，非日视图汇总选定范围，年折线按月汇总；日视图仍显示所选日期。清除范围后恢复快捷范围，以查看日期为基准。范围筛选作用于请求记录，热力图、折线和金额合计使用相同数据。

分析区默认简洁模式，保留每周曲线、窗口贡献、多周热力图、项目与对话排行及费用日历。模型比较只在至少两个模型有可比较记录时出现。高级分析保留全部分类与统计图。模式切换不改动额度策略、预测或模型筛选。

统计图使用日常语言说明关联情况，R² 与样本数放进默认收起的技术详情。每 1% 额度对应 Token 标注观测可信程度；不足五条记录显示数据不足，有断档/未完成导入/未识别账户或离散明显时标为有限参考。只有至少二十条且中间一半比值的上界/下界不超过 1.5、没有上述质量缺口时标为观测较稳定，仍不代表官方兑换率或统计置信度。图表说明移到标题旁的信息按钮，弱拟合线不再展示。
