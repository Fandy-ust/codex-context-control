# Context Manager 0.27.15

Windows now resolves the current registered Codex installation before reopening the desktop after account switching, using Open Codex, or checking an automatic account handoff. Microsoft Store updates can remove or retain the previous version directory; either case uses the current registered package without requiring a Context Manager reinstall or a source change.

Installing 0.27.14 could temporarily recover launching because the installer refreshed the stored executable path. This release also recovers after subsequent Store updates while Context Manager remains installed.

This release includes all 0.27.14 authorization link copying and embedded sign-in fixes. macOS retains its existing launch behavior. Both platforms use version 0.27.15.

The existing update.json and update-v2.json feeds, Windows ZIP update payload and macOS DMG format remain compatible with 0.27.14. Existing release assets are retained, and upgrades preserve local configuration and saved accounts.
