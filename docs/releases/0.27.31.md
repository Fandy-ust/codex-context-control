# Context Manager 0.27.31

Normal metadata discovery, numeric usage-tail scanning and full chat-state hydration focus on the latest 20 chats. Active connected work, waiting/running queues, pending context operations/handoffs and the current UI chat/queue remain explicit exceptions. Older chat records and saved budgets are preserved; opening them in Codex or requesting an ID loads metadata on demand without changing their activity order. `chat list --offset N` reads the lightweight native index in pages of 20.

The regular analytics scan reads recent sources plus active exceptions; previously stored history remains in the numeric ledger. Explicit analytics refresh can scan a wider bounded batch of older records. Statistics requested for a particular old chat still use its own bounded history workers. Account-switch safety reads live connection facts without hydrating every historical chat.

Both native macOS and Windows main-window refreshes use a two-second cadence; Mac menu controls retain a one-second cadence. The shared hot-state endpoint preserves the selected chat during activity changes. No official Codex binary, signing check, process ancestry, Chrome permission or queue authorization is changed. Version and executable hashes are verified after local installation. Windows hardware/browser validation remains distinct from CI.
