## 0.24.0 · 多设备云同步与持续额度监视

- 新增设置 → 云同步：GitHub 私有仓库和 Secret Gist，两端共用加密、合并和去重核心；支持同步间隔下拉、自定义间隔、手动同步和状态反馈。
- 每台设备独立上传数值记录，按 response ID 去重；区分账号，上传前加密，Token／密钥使用 DPAPI／钥匙串保存。不上传聊天正文或标题，不累加账号额度百分比。
- 增加完整[配置文档](https://github.com/Fandy-ust/codex-context-control/blob/main/docs/CLOUD_SYNC.md)，涵盖 Windows／macOS 界面及 GitHub CLI 配置。
- 每个聊天的额度监视可持续开启，队列完成后不自动关闭，并可保护后续手动轮次；设置新增全局监视开关。
- 修复 Windows 补偿开关 Unknown action；点击最近聊天不自动展开项目，保留侧栏位置。
- 增加滚动边缘渐变模糊、分离时间线事件标记、模型／思考程度变更标记，以及响应编号下的时间。
- 修复云同步标签点击后未切换页面的问题。

更新后请完全退出并重开 Codex，加载新的连接程序。云同步默认关闭，按文档自行配置后启用。

### English

- Encrypted multi-device numeric analytics via GitHub private repositories or Secret Gist, with account isolation, response-ID deduplication, configurable intervals and manual sync.
- Persistent per-chat quota monitoring and a global monitoring switch.
- Sidebar stability, scroll edge blur, separated timeline events with model/effort changes and response timestamps.
- Windows compensation action and Cloud sync tab navigation fixes. Both platforms share version 0.24.0.
