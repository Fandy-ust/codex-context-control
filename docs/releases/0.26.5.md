# 0.26.5 — Codex desktop startup compatibility

The Codex desktop app can invoke `app-server proxy` while reading startup policy. Context Manager now forwards this command to the bundled Codex executable without wrapping it as a direct stdio server or adding context overrides.

For direct stdio app-server sessions, an input EOF now closes the native input and gives the runtime time to finish its final response. A runtime that does not exit is still terminated after a bounded delay. The shared behavior applies to Windows and macOS.

Regression coverage includes proxy classification, graceful EOF completion, timeout cleanup, and Windows parent-process cleanup. The installed desktop app must be restarted after upgrading for the new launcher behavior to take effect.
