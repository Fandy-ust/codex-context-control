# Context Manager 0.28.0

- **上下文管理 / Context management:** opt in under Settings → Experimental. Enable individual chats or all eligible chats. Edit the Planner, status format, and cadence, and preview the result before saving. The per-chat log distinguishes a hook response from a native Codex acknowledgement. Optional system notifications cover reminders and accepted CLI expansion or compaction requests. See [experimental context reminders](../CONTEXT_REMINDERS.md).
- **续接 / Continuation:** the independent Settings → Automation → Queues & switching control lets a requested same-chat handoff run while ordinary queues remain paused. The scheduler still checks context and quota, and an upgrade preserves the former pause choice. See the [CLI guide](../CLI.md).
- **界面与账号 / Settings and accounts:** Accounts, Task queues and Account quota are directly available from Settings. Projects and Recent can be collapsed independently. Switching accounts preserves local project assignments while keeping cloud memberships separate.

The experimental feature is off by default and uses Codex's native hook trust flow. Windows PowerShell hook invocation has been corrected. Live testing verified acknowledgement in a regular desktop conversation; a tool-created first-turn test did not receive the Planner. Do not assume a reminder was delivered without a corresponding receipt.

See the [changelog](../../CHANGELOG.md) for the changes accumulated since 0.27.40.
