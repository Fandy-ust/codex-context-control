# Context Manager 0.27.34

The twenty-chat resource limit previously also truncated the main-panel list. Restore the full lightweight sidebar catalog on both platforms while retaining bounded hot state and usage scanning. Read the native metadata index once on service startup, cache titles/membership, and update entries from hot or explicitly selected chats. Manual local scan refreshes the full index. Reading the catalog does not scan cold history files.

The UI caches the full catalog, sends its revision on subsequent hot-state requests, and merges fresh recent/selected states into that cached display. Unchanged catalogs are not retransmitted. Clicking an old chat immediately loads its current state and refreshes numeric cache without modifying its activity order. Cold rows are cached observations, not live measurements. The statistics reinstall fix from 0.27.33 remains included.
