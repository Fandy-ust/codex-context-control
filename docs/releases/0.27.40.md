# Context Manager 0.27.40

This release brings the shared quota display, first-message and model-catalog fixes to macOS and Windows, on top of 0.27.36's account-switch project preservation and earlier null-config compatibility.

- **New chats:** send the first message with the budget loaded at creation. Later submissions, forked and resumed chats, and oversized first inputs still receive their applicable history or capacity checks.
- **Model discovery:** a cache containing only hidden models or missing the explicitly configured model no longer overrides the native model list. Context extensions that depend on a generated catalog resume on a later launch with a usable cache.
- **Quota display:** retain the last displayed quota and Credits during reconnect while waiting for a fresh reading. The display fallback does not authorize queued work or Credits spending.
- **Context planning:** the shared skill guides agents to assess retained evidence and likely growth at useful checkpoints, and plan compaction or handoff around the next task stage.

The Codex launch chain is unchanged. Fully quit and reopen Codex after installing to replace the running bridge. The two platform installers use the same version and shared core; Windows installer tests use an isolated test runtime.
