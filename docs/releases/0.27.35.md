# Context Manager 0.27.35

开启上下文扩展后，Codex 新建或恢复聊天可能发送 `config: null`。此前共用桥接层会直接读取空配置并崩溃，导致本地运行时连接中断。现在将空配置与未提供配置统一处理，同时保留现有上下文预算规则。macOS 和 Windows 共用此修复。

The shared bridge now treats an explicit null configuration like an omitted configuration when context extension is enabled. Starting or resuming a chat no longer crashes the bridge for this input; existing context budget behavior is preserved on both platforms.

Regression coverage checks default configuration normalization, forwarding of chat start/resume requests and continued forwarding of subsequent requests. This fix addresses the identified bridge crash; unrelated network or service failures may still occur.
