# 0.22.2 — EXP 任务编辑器与原生队列指令

本地更新，未上传或发布 Release。

- 提示词编辑器可放大到占满右侧区域，保留左侧栏；缩小时保留提示词、附件、模型和额度草稿。
- 支持复制粘贴图片、选择图片/文件和文件拖放。图片和文件统一排列为方形附件卡片，带缩略图/文件图标、名称及右上角移除按钮。粘贴图片保存在本机，执行前仍检查文件存在。
- 模型与思考程度改为紧凑面板：顶部程度名称、模型菜单、重置按钮、按真实模型能力显示的分段滑块；Mac 使用原生 Menu、Slider 与 AppKit 文本输入。
- 移除内部“额度类型”文本框及任务额度页的冗余说明，保留已有配置。
- 没有检测到 5h 窗口时隐藏 5h 保留比例、梯度和摘要。保护逻辑只核对实际可用窗口；无可用数据或数据过期时仍不启动新任务。
- 合并重复的“继续队列”按钮到监视开关；失败任务仍需单独重试。
- 队列任务可单独填写 `/compact`，直接调用原生压缩，确认压缩完成后才继续下一项。压缩失败暂停队列；其他未支持斜杠指令明确报错，不作为普通提示词发送。指令无需模型/思考程度/附件，所以压缩任务隐藏这些输入。
- 队列协议升级至 v3，避免旧桥把 `/compact` 当作普通提示词。更新后需完整退出并重开 Codex 一次。

Windows 和 macOS 同步源码，共用调度、额度判断、持久化、命令识别和接入协议。按要求未运行 macOS 编译或原生测试。

本地验证使用临时服务、模拟运行时和合成剪贴板图片，没有发送真实任务或修改用户剪贴板。Windows 界面冒烟包含放大、粘贴、缩略图、移除、草稿保留、思考程度和缺少 5h 的场景。
