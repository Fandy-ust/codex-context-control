# 0.22.0 — 额度保护与任务队列

Windows 与 macOS 同步加入任务队列、额度保护及重置恢复。Mac 使用原生 SwiftUI 表单和可排序列表。

- 每个聊天可单独开启监视，默认关闭。开启时可将当前正在执行的轮次加入队首。
- 后续任务各自填写完整提示词，支持添加、编辑、删除、拖动排序。前项正常结束后才发送下一项；失败不会跳过。
- 聊天页在上下文预算和上下文详情之间显示开关、状态、前两项任务及详情入口。详情页返回按钮固定在顶部。
- 分别设置 5 小时和 Weekly 的最低保留比例，任一触线都暂停自动执行。默认保留 20% / 10%。
- 达到保留线时等待当前 turn 结束；低于保留线 2 个百分点（如 20% → 18%）或为 0 时，请求原生中断。只控制队列发起或用户明确接管的轮次。
- 每种额度最多两级临近重置释放，例如平时 20%、最后 30 分钟 10%、最后 15 分钟 3%。重置后恢复基础比例。
- 支持重置后自动恢复、手动恢复，以及仅暂停当前周期。自动恢复需要重新读到有效额度和更新后的重置时间。
- 任务、顺序、设置及执行状态保存在本机。重启后未确认完成的任务关闭监视，核对进度后可继续，避免重复提交。
- 只有启用且仍有任务的队列才增加额度监视和系统防睡眠。队列完成自动关闭；关闭监视不会中断当前轮次，但不再发送下一任务。
- 设置新增“任务队列”页面，可统一查看及关闭全部监视，解除队列防睡眠。
- 中英文界面同步更新。

额度监视最多约每 10 秒读取一次本机账户额度。额度读取失败或过期时不会启动新轮次；网络及服务更新存在延迟，保留比例不是服务端的硬额度保证。上下文不足时会暂停任务并提示先手动压缩。
