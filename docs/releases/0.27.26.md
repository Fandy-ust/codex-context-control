# 0.27.26

Fix duplicate notify keys after restoring a legacy Codex configuration. Codex desktop startup recognizes a bare notify key but can append a duplicate when an older restore point uses a quoted key. Recovery now normalizes that root key spelling, verifies semantic equivalence, and preserves original backup bytes. Both manual restore and automatic offline repair use the same preparation, including jobs queued by an older version.

Conflicting duplicate keys are rejected rather than silently merged. Existing offline guards, staged validation, checksums and rollback journals remain in place. Shared behavior applies on Windows and macOS; native macOS execution requires validation on macOS.
