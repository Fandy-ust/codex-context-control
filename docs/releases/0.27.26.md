# Context Manager 0.27.26

Fix a desktop fork startup sequence that selects a default model and immediately returns to the parent model. The numeric history observation now retains evidence for the measured model while settings change, and reuses it only when the selected model/provider matches and no new content or unfinished turn invalidates it. This unblocks budget preflight before the fork's first message without weakening shrink checks, replaying messages or sending measurement prompts.

The fix is shared by macOS and Windows. It does not change the Codex executable, its signature, browser permissions or peer-authorization checks. Browser native-pipe authorization is under separate investigation; this release does not claim to repair it.
