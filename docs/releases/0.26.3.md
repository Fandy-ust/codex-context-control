# 关键更新 / Highlights

## Windows 安装包架构升级

- Windows Setup 改用内嵌 LZMA2 压缩，相比旧 ZIP 安装包体积约减少 29%，仍是单个 EXE，使用者无需安装解压工具。
- 继续使用正式版安装目录、聊天、登录、预算和偏好，支持原来的覆盖升级方式；本次发布不使用 Lab 隔离配置。
- 自动更新下载包保持标准 ZIP，兼容原有更新机制。LZMA2 只影响安装包的存储与解压，不改变模型、上下文算法或聊天内容。

## 修复频繁出现的接入进程冲突

- 修复客户端退出后，旧接入进程和原生运行时仍然存活、再次登记聊天的问题。已在 Windows 上确认过旧版孤儿进程与新版进程同时占用同一聊天的情况。
- 为 Windows 和 macOS 共用的接入核心增加输入断开、输出管道断开、父进程消失及包装进程退出时的子进程清理，并在原生进程不退出时执行限时强制清理。
- 两个客户端真实同时加载同一聊天时，继续保护性禁用上下文修改，显示“检测到多个接入进程，请完整重启 Codex”，不自动抢占活跃任务。
- 已经遗留在内存中的旧版本进程没有新的清理逻辑；升级时请结束旧客户端及其旧接入进程。新版本启动的连接会自动清理。

## 额度启动、通知与设置

- 新增周重置后 GPT-6 Luna 短消息探测、一次性定时启动和基于近期用量的“起床前提前多久”建议；探测收到回复即停止，每次最多三次。
- 支持 Windows/macOS 系统通知，区分 5 小时额度、每周额度及两者同时重置；合并相邻事件并持久化去重。
- 设置使用左右滑动开关。macOS 使用原生通知中心，首次需允许通知；后台管理器需保持运行。
- 保留 0.25.4 的大聊天历史分段读取修复。

## Validation / 验证

Windows 已验证孤儿接入进程清理后，受影响聊天恢复唯一连接；新增真实进程终止回归测试。GitHub Actions 会在 Windows 与 macOS 上分别编译、测试及校验安装包，双端通过后才发布。

macOS 的风险来自共用接入代码审查，尚无 Mac 实机故障复现记录；CI 编译与自动化测试不等同于人工实机通知体验验证。
