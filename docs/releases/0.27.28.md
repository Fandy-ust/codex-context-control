# Context Manager 0.27.28

This release integrates the browser-compatible launcher and agent context controls with the published main-branch fixes, preserving both platforms' existing settings, caches and history.

## Browser and runtime control

On macOS, the native launcher execs the unmodified official Codex as the desktop app's direct child, while the existing protocol bridge runs as a child of Codex. A desktop comparison verified that this layout restores Chrome/in-app browser discovery while keeping realtime budget control connected. It does not modify Codex binaries, signatures, browser permissions or peer-authorization checks, and does not add another Codex server. The bounded launch handshake validates preparation before consuming frontend input. Windows retains its existing native launcher and shared budget behavior.

## Agent CLI and skill

Current-chat summaries distinguish requested/loaded budgets, observation validity and estimated headroom. Read-only preflight separates budget validity, evidence and execution timing. Lightweight speed reports use existing numerical observations. Budget and idle-compaction operations have bounded receipts, stable request-ID deduplication, scoped inspection and cancellation. A user-agreed one-shot compaction can run after the exact current turn finishes; stale or uncertain intent is not replayed.

The skill defaults to quality-first and supports balanced/speed-first preferences, task-specific context assessment and interactive decisions. It continues safe work with ample headroom and yields at a checkpoint when an unresolved choice risks compaction. Automatic continuation/scheduler expansion remains paused.

## Preserved fixes

- A fork that briefly selects a default model and returns to its measured model/provider can reuse valid inherited numerical usage. New content, unfinished turns, compaction and rollback still invalidate evidence.
- Missing usage defers a budget change while allowing normal work under the current runtime configuration; the saved target is never reported as applied. Measured over-capacity and reload errors remain protected.
- Manual, automatic and previously queued configuration restores normalize legacy quoted notify keys only when semantic equivalence is preserved, avoiding duplicate-key startup failures and retaining original backups.

Both desktops share version 0.27.28. macOS retains SwiftUI/AppKit and Windows retains Electron/native Windows capabilities. Windows validation is automated CI, not manual hardware acceptance. Restart ChatGPT/Codex normally after updating to load the installed launcher; diagnostic scripts are unnecessary.
