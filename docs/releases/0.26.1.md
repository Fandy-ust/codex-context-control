# 0.26.1

This is the normal, non-isolated release. Windows Setup uses LZMA2 and upgrades the existing installation while preserving its data. It is distinct from the older Lab 0.26.1 installer.

- Settings switches now slide left/right, with a green enabled state and keyboard focus styling. macOS quota activation uses native switches.
- Chats registered by multiple connection processes show “检测到多个接入进程，请完整重启 Codex” and a connection-conflict status. Ordinary missing-model and disconnected-chat hints remain unchanged.
- Includes the quota activation and scheduling features from 0.26.0.
