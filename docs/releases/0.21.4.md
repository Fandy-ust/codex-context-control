# 0.21.4

Mac 和 Windows 同步新增 Token 费用日历，支持热力图与折线图、日/周/月/年范围和模型筛选。日视图按小时、周/月视图按天、年折线图按月汇总最近 12 个月；年热力图展示最近 365 天。

沿用聊天详情的 Standard API 价格与缓存写入估算，不代表订阅费用或真实 API 账单。无法计价的请求单独计数，无记录留空；部分可计价时合计只覆盖已计价部分。费用只来自本机 Token 日志，不随账户额度来源或额度池切换；受模型筛选影响，独立于高级分析的 4/8/12 周范围。

统计图增加同风格的悬浮详情卡片；滚动时隐藏，不占用滚轮。额度分析返回按钮与 macOS 默认设置返回按钮保持可见并使用现有带边框按钮。

历史保留扩展至 366 天，升级后增量重扫可访问的本机日志。不存在或已删除的旧日志无法补齐；本地记录仍有 250,000 条数量上限。
