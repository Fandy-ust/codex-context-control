### 更新重点 / Highlights

- **实验性上下文管理**：可为单个聊天或所有聊天启用，支持调整 Planner、状态框和更新频率；聊天日志可查看发送的提示词及 Codex 接收回执。
- **同聊天续接**：独立于普通任务队列的全局监视，仍会检查轮次、上下文和额度。
- **桌面设置**：整合账号、任务队列和额度入口，切号时保留本地项目分组。

Experimental Context Planner and status updates now support per-chat or global opt-in, configurable text and cadence, and a per-chat delivery log. Same-chat continuation has its own switch. Settings are consolidated, and account switching preserves local project assignments.

升级后请完整退出并重开 Codex；使用实验性功能时，在 Codex 的 Hooks 设置中审核并信任更新后的 Hook。通过工具创建或驱动的聊天可能收不到原生 Hook 注入，请以对应聊天的日志为准。

After upgrading, fully restart Codex. For experimental reminders, review and trust the updated hooks in Codex. Chats created or driven through tools may not receive native hook injections; check the chat's log.
