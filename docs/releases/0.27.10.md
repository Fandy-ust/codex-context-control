# Context Manager 0.27.10

Saved account switches now run directly from the quota sidebar and account settings on macOS and Windows. Clicking switch pauses queues, closes Codex/CLI sessions, verifies the selected account, writes its credentials, and reopens the desktop app. Active tasks are interrupted.

Background services can start another Codex process while the selected account is being verified. Manual switching now stops newly matched processes during shutdown and repeats shutdown immediately before the final credential check. If shutdown or identity validation fails, the active credentials are preserved. Automatic queue handoffs continue to cancel when an unrelated session appears.

The macOS installer displays its product version so multiple mounted installers are easier to distinguish. A large cloud-sync view was split into smaller expressions to resolve Swift compiler type-check timeouts.

## Installation and validation

Use the macOS Apple Silicon DMG or Windows x64 Setup.exe. Updates preserve existing configuration and history. macOS builds are locally signed and are not Apple notarized unless the published package metadata explicitly states otherwise.

Regression tests cover supervisor restarts during validation, newly appearing shutdown targets, failed shutdown preserving credentials, and automatic handoffs refusing new sessions. CI must pass both platform build and installer checks before publication. Real account switching with a live background supervisor still requires user validation; mock regression tests do not establish a successful live switch.
