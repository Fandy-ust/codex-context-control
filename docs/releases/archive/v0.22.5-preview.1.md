# 0.22.5 · 任务编辑器与额度图表

本次包含 0.22.0 之后的累计更新，Windows 与 macOS 使用相同版本与共享队列、费用和额度分析核心。

## 这次修好了什么

- 修复粘贴图片时报 `clipboard.readImage is not a function`：适配 Electron 44 的异步剪贴板接口，支持截图、复制的照片及文件；普通文字和路径仍可作为文字粘贴。
- 任务输入框顶部直接排列方形附件卡片，图片显示缩略图，文件显示名称，每项可单独移除；没有附件时直接显示正文。
- 统一加号、权限、模型和发送按钮的高度与水平对齐，去掉模型旁多余的向下箭头、右上角放大按钮与对应留白。模型仍可点击打开闪电图标与思考程度面板。
- 保留简洁的当前周期额度预测，优先显示剩余多少、预计何时用完及能否撑到重置。此图也能比较多个周期，重叠默认关闭。
- 新增的费用比例／历史周期比较图放在预测下方，支持 5hr、Weekly，以及每消耗 1% 额度对应的本机预估 API 费用；默认比较最近 6 个实际观测周期，可选 3／6／12 个。
- 日期范围与图例放在同一底栏，周期切换按卡片居中。略微加粗曲线、保留小数据点；悬停详情只显示在悬浮卡片中。
- 新增关闭／低／中／高平滑程度。平滑按周期、连续数据段分别计算，不跨越断档；费用比例按额度变化加权，悬停保留原始读数，预测不受平滑影响。

## 从 0.22.0 累计改进

- 每项队列任务可单独设置提示词、附件、模型、思考程度、审批权限、5 小时／Weekly 保留额度与最多三个临近重置释放梯度；聊天配置作为新任务默认值。
- 监视开关可接管当前执行中的任务；队列完成自动关闭，无任务时不持续监视或阻止睡眠。设置内可集中管理与关闭监视。
- 支持后台连接聊天，无需先在 Codex 中点击对应窗口；支持重试及 `/compact` 简单指令。
- 修复预算已经保存仍阻止队列启动的情况，保留预算安全预检与提交确认；权限默认沿用当前聊天，也可为任务重新选择。
- 未完成任务保持执行顺序，已完成任务放在后面，完成超过 12 小时自动归档。
- 提高额度采样频率，保留已观测到的每次百分比及 Credits 变化；增加 Credits 历史、完整重置周期与自定义日期范围。
- Mac 使用 SwiftUI Menu、Popover、Picker、Toggle、DatePicker，以及 AppKit 原生文本与剪贴板接口，同步任务编辑器与图表交互。

**任务队列、额度保护与自动恢复仍为 EXP 实验性功能。** 额度来自最近观测，暂停存在执行与刷新延迟；费用只包含可计价的本机 API 估算，不是订阅账单。

安装后请完整退出并重新打开 Codex，使新版桥接程序生效，再重试之前失败的任务。更新保留原有配置与记录。
