## 0.17.0 — Local cache & in-app updates / 本地缓存与在线更新

Download the DMG below, open **Install Context Manager.app**, choose **Install / Update**, then restart Codex.

下载下方 DMG，打开安装器，点击「安装 / 更新」，然后重开 Codex。

### What's new / 更新内容

- **Startup cache:** local chats and their last recorded usage appear without opening every chat in Codex. Cached data is labeled separately from live connections.
- **Incremental sync:** unchanged files are skipped; complete appended records are read in the background. Use **Sync local chats** for a manual refresh.
- **Click-to-install updates:** check GitHub automatically every six hours; download and install only after you click. Downloads and installer contents are verified. Budgets, language, and caches are preserved.
- **920K stays available**, using the official Codex runtime. The modified early-compaction core remains disabled to preserve Computer Use compatibility.

- **启动缓存**：无需逐个打开 Codex 聊天，即可查看本地记录中的模型和最近用量，明确区分缓存与实时连接。
- **增量同步**：跳过未变化的文件，后台只读追加内容，也可点击「同步本地聊天」。
- **在线更新**：每六小时自动检查，点击后才下载、校验和安装，保留预算、语言和缓存。
- **继续支持 920K**，保留官方 Codex 核心；提前压缩修复仍关闭。

**Install 0.17.0 once to enable future in-app updates. / 旧版本需先安装一次 0.17.0，之后即可在应用内更新。**

Apple Silicon · macOS 14+ · DMG, about 45 MB. Cached data comes from bounded local history reads; remote-only or missing records require Codex to sync first. Historical usage does not authorize live budget changes or compaction.

Validated: full regression suite (128 passed, 4 conditional skips), additional updater failure/retry checks, and native unattended installation with budget/cache preservation. The installer is locally signed, not Developer ID signed or Apple notarized; if macOS blocks a trusted download, use Privacy & Security → Open Anyway.
