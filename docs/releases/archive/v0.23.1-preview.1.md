## 0.23.1 · 一键安装 Agent Skill

- `context-manager skill install` 将内置 skill 安装到 Codex 的个人 skills 目录，Mac 与 Windows 用法一致；其他 agent 可通过 `--path` 指定目录。
- 更新 App 后重复运行同一命令即可更新 skill。保留本地修改及其他文件，覆盖自行修改的技能需显式加 `--force`。
- GitHub 同步维护技能源码、用途说明和中英文安装指南。
- 包含 0.23.0 的独立提前压缩补偿开关、全局／聊天／队列 CLI 和只读速度分析；补偿默认关闭，目标容量以 App 为准，极端长度不保证完整补偿。
