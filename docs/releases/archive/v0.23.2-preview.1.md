## 0.23.2 · Windows 减重、侧栏与快捷控制更新

- Windows 安装包裁掉无用的分词表、重复模块和未使用的 Chromium 语言资源；保留中文、英文、图形兼容组件和独立 Node，CLI 与后台服务继续可用。
- 提高 ZIP 压缩率，安装仍只需一个 Setup.exe；旧版更新器可继续读取新 OTA 包，无需额外安装解压工具。
- 启动时额度图标从底部描边，再填充到实际额度；运行中的聊天显示持续更新的响应速度、小折线和红绿升降箭头；速度 ≥40 为绿、30–39.9 为黄、低于 30 为红。菜单调节区移除叉并加宽「应用」。
- 最近列表可折叠并记住状态，折叠后与项目行等高；项目与最近共用一个滚动区域，按展开内容动态占用空间。
- 项目改用打开／关闭文件夹图标，移除展开箭头，悬停时整行高亮；移除项目和最近列表底部的模糊光带。
- 侧栏顶部版本号旁新增「有更新」快捷按钮，点击安装；下载／安装时显示「更新中」。
- 修复发现旧更新后无法继续检查新版的问题：两端始终保留「检查更新」，手动检查获取新结果，安装前再次检查最新版。
- 更新来源不可用时显示原因，保留已知版本信息，不静默安装过期缓存。
- 包含 0.23.1 的 CLI 与 skill 一键安装，以及独立提前压缩补偿开关。两端产品版本一致。
