## Original release notes

## 0.17.1 — Replace old versions, reclaim disk space

Updates now remove unused older bundled runtimes and the disabled legacy compaction core after successful installation. Files still used by running processes are retained temporarily and checked again every five minutes. The app and program code continue to be replaced in place.

Budgets, language settings, chat caches, and user backups are preserved. OTA download files are removed when the update finishes. Manually downloaded DMGs are left alone.

## 更新后自动清理旧版本

成功安装后会清理不再使用的旧运行环境和已停用的压缩修复核心，App 与程序代码继续原位替换。

仍被进程使用的旧文件暂时保留，退出后自动清理。预算、语言、聊天缓存和备份不受影响；OTA 下载文件在更新结束后删除，手动下载的 DMG 不会自动删除。

**0.17.0 用户可在应用内点击「检查更新」，再点击「安装更新」。** 新用户下载下方 DMG 安装即可。

Apple Silicon · macOS 14+ · about 45 MB. Locally signed preview; not Developer ID signed or Apple notarized.

Upgrade inheritance now preserves unknown preference fields and newer schema markers. A single lightweight configuration snapshot is retained before version changes; reinstalling the same version does not duplicate backups.

升级继承会保留预算、语言、开关、缓存及设置中的未知字段；升级前仅保留一份轻量配置快照，同版本重装不会重复生成备份。
