## Original release notes

## 0.18.3 — More reliable update checks

- Check the public release manifest first, avoiding routine dependence on anonymous GitHub REST API limits. Use the API only as a fallback.
- Distinguish rate limiting from other HTTP 403 refusals, connection failures, and invalid metadata. Honor retry/reset times and throttle repeated clicks.
- Show retry timing and a manual release-page download link. No GitHub token or account setup is required.
- Verify the downloaded image against both the manifest hash and checksum file, then run the existing payload verification.

## 更新检查修复

- 优先读取公开版本文件，减少对匿名 GitHub API 的依赖；失败时才使用 API。
- 区分限流、普通 403、网络失败和无效版本信息，遵守重试时间，避免重复请求。
- 检查失败时提供重试时间及手动下载入口，不要求用户配置 GitHub Token。
- 保留下载校验、安装内容校验，以及原有预算、设置和缓存。

**If your old updater still reports HTTP 403, manually install this release once. You can skip intermediate versions.** A network that blocks GitHub downloads may still require a working network or manual transfer; this update does not guarantee every 403 disappears.

**旧版若仍报 HTTP 403，请手动覆盖安装本版一次，可以直接跨版本升级。** 若网络本身限制 GitHub 下载，仍需使用可访问的网络或手动传递安装包。
