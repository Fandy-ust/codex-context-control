## 本次更新 / What’s new

修复额度分析在空闲后重启时可能偶发读取失败的问题。旧统计 worker 会先关闭本地账本，新 worker 等它退出后再启动，避免 Windows 文件锁竞争。

Mac 与 Windows 同步更新，保留 0.20.0 的额度分析、界面对齐和全部数据。

Fix an intermittent quota-analytics startup failure after an idle period. Workers now close the ledger cleanly and finish exiting before a replacement opens it. Both platforms share this update; analytics, budgets and user preferences are preserved.
