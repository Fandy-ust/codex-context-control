Context details now appear below the budget controls on both platforms. One slider group and an explicit Apply button replace redundant actions. Analytics automatically selects useful records, hides unsupported 5h views, and tolerates reset countdown rounding. Same-cycle gaps can produce labelled net-change comparisons without inventing hourly usage.
