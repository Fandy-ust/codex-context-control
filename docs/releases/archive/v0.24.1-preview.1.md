## 0.24.1 · 云同步凭据复制与 Mac 同步入口修复

- 取消同步密钥至少 16 个字符的要求，非空即可。
- 保存后 Token 和密钥保留圆点及“已保存”标记；两者均可随时复制，重新打开设置后仍可复制。
- 修复 Mac 填好配置后同步按钮仍为灰色的问题：支持直接“启用并同步／保存并同步”，自动保存当前输入并启用同步。
- 同步前刷新账号额度；凭据写入后读回校验，避免保存失败却显示成功。
- Windows 与 macOS 同步更新，保留现有凭据和同步数据。

### English

- Remove the 16-character minimum for nonempty sync keys.
- Keep saved credentials visibly masked, with persistent Copy Token / Copy key actions.
- Fix the grey Mac sync button: Enable and sync / Save and sync saves the current form and starts sync directly.
- Refresh account quota before syncing and verify OS credential writes by reading them back.
