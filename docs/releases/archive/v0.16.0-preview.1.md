## English and Chinese UI

Context Manager 0.16.0 adds English / 中文 selection throughout the app, menu bar, context details, charts, status messages, Stop hook, and installer. Choose **Automatic (time zone)**, **中文**, or **English** in the main window’s sidebar.

Automatic mode uses Chinese for mainland China, Hong Kong, Macao, and Taiwan time zones, and English elsewhere. A manual choice takes priority and is saved locally. Switching is immediate and preserves chat names and budgets. The README and core usage/development guides now have language links.

Original project code is now **MIT licensed** as selected by the owner. Third-party notices and licenses are retained.

## 安装 / Install

Download `Context-Manager-0.16.0-macos-arm64.zip` (about 49 MB), extract it, open **Install Context Manager.app**, and choose **Install / Update**. Fully quit and reopen Codex after the first installation or a bridge upgrade. No Node, Homebrew, or Xcode is required. Supports Apple Silicon, macOS 14+, verified Codex runtime 0.160.0.

下载 ZIP，解压并打开安装器，选择「安装 / 更新」。首次安装或桥接更新后请完整退出并重开 Codex。语言在主窗口左侧可选「自动（按时区）／中文／English」，立即生效并保存；更新保留预算、功能开关和语言偏好。

This preview is locally signed, **not Developer ID signed or Apple notarized**. For a trusted download blocked by macOS, follow Privacy & Security → Open Anyway. 本测试包尚未 Apple 公证，首次打开可能需要在「隐私与安全」中允许。

The large optional patched runtime is not included. No credentials, chat history, or author settings are bundled.
