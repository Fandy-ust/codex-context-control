## 额度分析 / Quota analytics

Mac 和 Windows 使用同一版本、同一统计核心，并对齐侧栏、Credits 指示和分析页布局。

- **6 张主图**：Weekly 曲线、5h 窗口贡献、Token vs Weekly%、Token vs 5h%、Token / 1% 效率、多周热力图。
- **更多分析**：累计双轴、模型与缓存比较、分布、箱线图、近期速度预测、异常窗口、日内热力图、5h/weekly 比值，以及本机对话和项目 token 排行。
- **本地缓存**：后台分批导入已有数字记录，后续只读新增内容。请求去重，fork、压缩和回滚不会重复计入消耗。
- **统一口径**：缺失周期不会显示成零；重置和断档不会生成虚假的消耗。换算展示本机相关观测，不代表官方固定兑换率；其他设备的使用可能影响比较。
- **界面对齐**：Mac 新增与 Windows 一致的 Credits 圈、顶部设置入口和详情页工具栏；两端共用 Credits 基准与重置逻辑。

Mac and Windows share the same release and analytics core. The Overview contains six essential charts; three further sections cover trends, comparisons and window details. Incremental local history imports are deduplicated and kept in a numeric ledger. Quota resets, missing records and mixed-model observations are handled explicitly. Token/percentage figures are local correlations, not official conversion rates. Updates preserve existing budgets, preferences and compatible Credits baselines.

真实额度与 token 记录按本机情况显示；没有 5h 数据的账户会显示暂无记录。预测需要足够的近期观测，对话排行不虚构逐聊天额度消耗。
