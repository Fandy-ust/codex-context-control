## 本次更新 / What’s new

修正整数百分点下的预测口径：按有效观测时间计算平均消耗速度，以小时聚合估计较慢／较快场景。短时间额度读数不跳动，不再被误当成未来完全不消耗。

保留 0.20.1 的统计 worker 重启修复，以及 0.20.0 的六张主图、增强分析和双平台界面对齐。Mac 与 Windows 同步更新，预算、缓存与偏好保留。

Correct quota projections when readings are rounded to whole percentage points. The central line now uses observed consumption per hour; slower/faster scenarios use hourly aggregates. The release retains reliable worker restarts, all analytics views and the aligned Mac/Windows interface.
